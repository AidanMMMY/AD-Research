5. 运维要点

  • 10 个 job：news_wechat2b_w2[a-j]_60m，每小时；健康面板"公众号二批 X 组"。
  • 缺文排查先看 etl_log + normalize SQL error（7-27 截断 P0 教训）；source_id 已加宽 500。
  • bestblogs 是公益实例：整域失效时按 runbook §5.2 删行/下 job；禁止运行时放大重试。
  • wewe-rss 通道 B 恢复需用户重新扫码（AuthCode 123567，SSH 隧道到 4000 端口）；feed.add 间隔 ≥10s。
  • 已知问题：wewe-rss 现有 8 号 body 为空（缺 mode=fulltext），属既有源改进，本批未动。
  • 本批保留 WechatMarketingFilter（门户号偶发软文由 LLM 拦截，rejected_marketing 入 etl_log）。
